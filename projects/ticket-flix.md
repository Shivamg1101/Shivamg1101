# Ticket Flix

Movie ticket booking interface with seat selection and showtime browsing.

**Source: [github.com/Shivamg1101/Ticket-Flix](https://github.com/Shivamg1101/Ticket-Flix)** — public.

## What it does

- Browse showtimes and pick a screening
- Interactive seat selection with unavailable seats blocked
- Booking summary before confirmation

## Notes

A personal project, built while learning front-end fundamentals — no framework, just
JavaScript, HTML and CSS against the DOM directly.

The seat map is the interesting part: seat state has to stay consistent between what the
user sees and what is actually selectable, which is the same class of problem a framework's
state layer solves for you. Doing it by hand first is a good way to understand what that
layer is actually for.
